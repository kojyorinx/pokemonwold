# pokemonwold

YouTube のライブ配信チャットを [ポケモンWordle](https://wordle.mega-yadoran.jp/) に連動させる Windows アプリです。採用したコメントのポケモン名を、本家サイトのキーボードへ自動で入力します。

## 起動

`dist/pokemonwold.exe` をダブルクリックします。操作画面と、本家サイトのウィンドウが開きます。配信画面には本家サイトのウィンドウを映してください。

設定は exe と同じフォルダの `settings.json` に保存されます。API キーが含まれるため、このファイルは共有しないでください。

## 採用ルール

- 対象はライブ配信チャットです。通常の動画コメントは使いません。
- 全角カタカナだけのコメントで、ポケモンの名前と一致したときだけ抽選します。
- 通常コメントの採用率は 10% です。スパチャは金額ごとの段階で採用率が上がります。
- 採用率と金額の段階は、操作画面から変更して保存できます。
- 採用したコメントは「表示名さん、ポケモン名」と読み上げます。Windows に日本語の音声が入っていると、その音声を使います。
- 操作画面で「今日のお題」と「エンドレス」を選べます。選んだモードの盤面へ入力します。エンドレスは、本家サイトの START を押してから入力できます。
- ゲームをクリアすると、最終コメントの人を出すウィンドウが開きます。下には日本時間の今日の正解数ランキングが出ます。配信画面にはこのウィンドウも映せます。

## 配信なしで試す

「配信なしで試す」に全角カタカナのポケモン名を入れて「テスト送信」します。配信チャットと同じルールで判定し、採用した名前を本家サイトへ入力します。「テストでは必ず採用する」をオンにすると、名前の条件を満たしたコメントは採用率の抽選を通さず本家サイトへ送ります。「クリア画面を試す」は、表示名とコメント欄の名前でクリア画面とランキングの表示を確認します。

## ライブ配信チャットへ接続する

1. Google Cloud で YouTube Data API v3 を有効にし、API キーを作ります。
2. 操作画面に API キーと、配信の URL または動画 ID を入力します。
3. 「配信チャットに接続」を押します。接続後に付いたコメントから判定します。

開発中は、このフォルダで `npm install` のあと `npm start` です。確認用のテストは `npm test` です。
