# pokemonwold

YouTubeライブのチャットと、ポケモンの名前を当てるWordleを同じ盤面で進める配信向けツールです。視聴者がチャットに名前だけを送ると、OBS用オーバーレイの共有ボードが更新されます。

ポケモンの名前・図鑑番号は [PokeAPI](https://pokeapi.co/) の日本語名（全国図鑑1025匹）を同梱しています。本ツールは非公式のファン作品です。ポケットモンスターの商標・権利は株式会社ポケモン、任天堂、ゲームフリーク、クリーチャーズに帰属します。

## 遊び方

- 出題は毎回1匹。文字数は名前に合わせます。
- チャットにはポケモン名だけを送ります。ひらがなでも判定します。
- 緑はその文字が正しい位置、黄は名前に含まれるが位置が違う、灰は含まれません。
- 配信全体で6回まで。視聴者は1ラウンドにつき1回、配信者とモデレーターは複数回答えられます。
- 配信者とモデレーターは `!new` で出題し直し、`!open` で正解を開けます。

## アプリケーション

`dist/pokemonwold.exe` をダブルクリックすると、ポケモンWordleのウィンドウが開きます。標準ブラウザは起動しません。ホストトークンはウィンドウへ自動入力されます。

配信画面に載せるボードは、ウィンドウに表示されるURLをOBSのブラウザソースへ入れます。プレビューもアプリ内の別ウィンドウです。

YouTubeで配信していなくても、ホスト画面の「テストモード」から視聴者のチャットを再現できます。ポケモン名だけの発言が回答になり、モデレーターとして送ると `!new` と `!open` も試せます。

トークンや動画IDを固定したいときは、exe と同じフォルダに `.env` を置きます。項目は `.env.example` と同じです。

開発中に同じウィンドウで起動する場合:

```bash
npm install
npm start
```

作り直す場合:

```bash
npm run build:exe
```

## 起動

```bash
cp .env.example .env
npm start
```

YouTubeへ接続するAPIキーはアプリの入力欄から渡し、画面の状態表示には残りません。

## YouTubeライブチャット

1. Google Cloud で YouTube Data API v3 を有効にし、APIキーを作ります。
2. 配信中の動画URLにある `v=` の値を動画IDとしてホスト画面へ入れます。
3. 「チャットに接続」を押すと、接続後に届いたテキストチャットだけを回答として読みます。接続前から残っているチャットは無視します。

APIキーのない状態でも、ホスト画面の「テスト回答」から盤面を進められます。
